# Admin — PinkyBua notes

## Users and Roles
Invite a user by email, assign a role in this wedding with an optional start and expiry, suspend or reactivate. Suspension takes effect on the user's next request. Role permissions are edited by a super admin and apply to every wedding. The last super admin cannot be removed.

## Audit log
Every admin action, ledger change, import, link rotation and assistant action is recorded. Filter by person, action and date.

## Integrations
**Integrations** shows recent text-to-speech results, whether spoken announcements (voice_calls) are on, and NudgeBee recommendations. Approving a recommendation turns voice_calls off only after Flagsmith confirms it.

## What PinkyBua can answer for an admin
- **Functions**: date and time, families invited, attending, not attending, no answer yet, planned plates, families checked in, the queue and the token now on stage. Ask about one function by name (Haldi, Sangeet, Reception) or all of them.
- **Guests**: find a family by name or token number, or list who is attending, not attending or has not answered a function. For each family it shows the token, language, RSVP per function with the guest count, and where they checked in. Phone numbers are never shown.
- **Photos**: how many photos are Matched, Check this or Unmatched for each function.
