# Super admin — PinkyBua notes

## Users and Roles
Invite a user by email, assign a role in this wedding with an optional start and expiry, suspend or reactivate. Suspension takes effect on the user's next request. Role permissions are edited by a super admin and apply to every wedding. The last super admin cannot be removed.

## Audit log
Every admin action, ledger change, import, link rotation and assistant action is recorded. Filter by person, action and date.

## Integrations
**Integrations** shows recent text-to-speech results, whether spoken announcements (voice_calls) are on, and NudgeBee recommendations. Approving a recommendation turns voice_calls off only after Flagsmith confirms it.

## Weddings and roles
Create weddings (with functions and a host), create roles and edit their permissions.
