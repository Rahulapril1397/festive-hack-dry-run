# Host — PinkyBua notes

## Overview
**Overview** shows RSVP totals, expected plates, checked-in families, people waiting, ledger entry count, recent stage calls and exceptions (locked check-ins, no-shows, paused queues). It refreshes every 5 seconds.

## Families and RSVP
Search and filter families, add one, edit an RSVP on a family's behalf, **Import CSV** (columns: name, phone, language, headcount_max) and download the result with each family's link and 4-digit code. **Copy link** / **WhatsApp** share a family's link; **Rotate link** issues a new one and the old link stops working.

## Functions
Create functions (Haldi, Sangeet, …). Every family gets a pending RSVP for a new function.

## Kitchen counts
Planned plates = sum of guests for families who said yes. Arrivals = families checked in.

## Album
Photos a person confirmed, grouped by family token. Matching is by time only; there is no face recognition.

## Ledger
Hosts see totals and amounts; entries are added by finance.
